
É importante termos um ambiente virtual pos assim, padronizamos a versão do django que está sendo utilizada, evitando que tenhamos que instalar diferentes versões para evitar problemas de compatibilidade

Ativar o ambiente virtual

```bash
source .venv/bin/activate

pip install django
pip install djangorestframework
pip install djangorestframework-simplejwt
pip install django-cors-headers
```
